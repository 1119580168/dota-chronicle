# Dota Chronicle · DOTA 2 编年馆

完全离线的 Windows 桌面档案馆：按时间线浏览历史 Dota 2 客户端、官方活动与游廊地图，启动本机收藏，并创建本地房间。源码公开，采用 **PolyForm Noncommercial 1.0.0** 非商业源码许可。

## 快速使用

1. 从本仓库 Releases 下载 Windows x64 ZIP，完整解压到可写目录，运行 `Dota Chronicle.exe`。保留程序相邻文件，升级时保留 `data` 文件夹。
2. 打开 Steam 并使用自己的账户登录。在“我的版本库”绑定历史客户端根目录，或扫描收藏目录。
3. 在时间线选择“本机可用”版本，点击“主菜单”或“进入普通比赛”；可选择包内已有界面语言。
4. 在“RPG 档案”选择活动或游廊。第三方地图需自行取得并绑定匹配指纹的原包；需要兼容入口时按界面提示备份并准备。

发行包不需要 Node.js、Python 或开发工具，**不含游戏客户端、Steam DLL、原始地图、私人绑定或图片视频**。新安装默认没有本机收藏；请自行准备客户端和媒体。公开下载入口仅为来源线索，不能作为授权、完整性或玩法兼容的保证。

## 能做什么

- 按年份浏览编号补丁、字母修订和早期客户端更新；区分“本机可用”“有可用版本”“未收藏”。
- 独立保存各构建的界面语言、启动配置和实际校验指纹。
- 官方 RPG 与游廊分别展示；本地图片和 WebM 支持原图及全屏播放。
- 创建客户端本地房间；7.32 / build 5397 另有同版本专服适配器。
- 7.22 原生英雄试玩和 7.27c 阿哈利姆迷宫可启用游戏内技能编辑器；原技能保持只读，新增技能的复杂依赖不保证通用兼容。

档案馆界面没有账号系统、遥测、自动更新或运行时 CDN。**Steam、游戏及第三方地图的网络行为独立于档案馆**；例如 WikiBox 历史包会自动请求作者服务，不属于严格断网地图。

## 本地房间

在“本地房间”选择客户端、地图、监听地址、UDP 端口和房间密码。房主与来客使用相同的实际构建和地图原包，并各自登录 Steam。可通过档案馆“加入房间”，也可在游戏控制台输入：

```text
password "your_room_password"
connect 192.168.1.25:30323
```

此地址只是局域网示例；异地连接需要实际可互访的虚拟网络地址或入站公网 UDP。程序不修改防火墙、路由器或转发端口，不生成公网地址。不要分享控制通道、RCON、本机配置或日志。技术路线已验证，跨电脑两账户与公网多人尚未统一验收。

旧版选队、专服与活动限制见 [本地房间说明](docs/local-rooms.md)。

## 本机数据与恢复

配置、会话、备份保存在程序旁的 `data`；媒体另存本机媒体库。关闭档案馆窗口可以保留游戏，重新打开后继续管理本程序拥有的会话。停止和恢复会校验 PID、可执行路径、创建时间及文件指纹，保留外部更改。

容量保护默认没有特定盘符或固定保留线。需要时手工创建 `data/storage-reserves.json`：

```json
{
  "schema": 1,
  "reservesGiB": { "Q:": 10 }
}
```

将示例盘符和数值换成自己的设置；数值单位 GiB，可为 0 至 16384 的有限非负数，盘符不区分大小写。只有配置的磁盘受此检查，剩余容量必须严格超过保留值。不存在配置时不加此限制；格式错误、读取失败、符号链接或目录联接会报错，请修正后重试。此设置不会删除或移动游戏。

[客户端归档](docs/client-archives.md)、[媒体库](docs/local-media.md) 和 [启动语言与控制台](docs/client-launch-options.md) 提供详细说明。

## 开发与打包

Windows 10/11 x64，Node.js 22.12 或以上。首次安装开发依赖和准备 Electron 运行时需要网络；之后构建使用本项目安装的运行时，已打包发行版离线使用。

```powershell
npm ci
npm run prepare:electron
npm run build
npm test
npm start
npm run release
```

`start`、`pack` 和 Electron UI 测试会先检查/准备运行时；干净克隆不需要手工复制其他项目的 `node_modules`。

生成 `release/win-unpacked` 和 `release/Dota-Chronicle-0.3.9-win-x64.zip`。当前二进制没有代码签名。资源编译需要用户自行安装的对应构建工具；原创编译 Panorama 资源随源码保存，原游戏工具不分发。

`src` 为作者源；`src/ui/assets`、`src/ui/styles.css`、`release` 为生成物。不要提交游戏、私人数据、原日志、转储或媒体；上传前检查排除规则。构建、测试和兼容性记录见 [设计与实现](docs/design-and-implementation.md)，版本演进见 [CHANGELOG](CHANGELOG.md)。
