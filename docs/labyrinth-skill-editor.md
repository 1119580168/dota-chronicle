# 7.27c 阿哈利姆迷宫：游戏内技能编辑器

适配对象是档案馆的 **7.27c / build 4397**、官方 `aghanim` 插件、`main` 地图。它使用独立的服务端模块与 Panorama 资源；7.22 原生试玩编辑器和当前版桌面编辑器继续使用各自的实现。

## 操作与范围

进入「RPG 档案」→「官方活动」→「阿哈利姆迷宫（7.27c）」，点击「启动迷宫 · 技能编辑器」。此入口准备临时工具文件，以单人作弊模式进入迷宫，并等待玩家锁定英雄后打开游戏内面板。普通「进入地图」仍采用原来的迷宫启动方式。

面板可搜索本机版本的原生技能、添加技能、调整新增技能的等级，以及移除本工具添加的实例。原来的迷宫技能保持只读，避免破坏地图任务与传奇碎片的技能归属。

关闭或收起面板不会删除已添加的技能。关闭会取消尚未完成的资源预载；新地图或新的英雄实例有独立记录。新增技能不会自动获得对应迷宫传奇碎片。Lua / datadriven 覆盖定义和迷宫专用技能不作为普通原生技能添加；隐藏技能、天赋、物品技能及复杂组合需额外确认。目录可选不代表跨英雄效果、声音、粒子与迷宫玩法全部兼容。

服务端要求本机监听服务器、作弊模式、单人房间、已初始化的 `GameRules.Aghanim` 与玩家实际拥有的非克隆英雄。前端只发送固定编辑动作；服务端检查引擎事件来源和新增技能的准确句柄，不接受任意 Lua 文本。选人阶段、地图不符、玩家增加、英雄切换与外部替换技能实例均不能绕过这些检查。

面板关闭后，可在同一合法会话使用控制台重新打开：

```text
chronicle_labyrinth_skill_panel open
chronicle_labyrinth_skill_panel close
```

源码入口已完成真实迷宫中的面板显示、事件往返、增删升级与固定施放验证；安装后的 0.3.7 也通过原生冷启动、面板交互及恢复检查。面板就绪以引擎认证的状态往返为依据。代码与命令示例见 [作者源说明](../tools/legacy-ability/7.27c/README.md)。

## 编译资源来源

本包的 `steam.inf` 为 `ClientVersion=4397`、`ServerVersion=4397`、`SourceRevision=6003565`，日期为 2020-07-19。原生迷宫的布局、脚本和样式资源均为 **resource header 12 / resource version 3**。原创面板必须使用相同资源格式，不能直接复用当前版脚本格式 4 的产物。

7.27c 包内含当期 `resourcecompiler.dll`，缺少命令行 EXE。检查后使用已核实的 7.22 通用 EXE 加载器在私有目录调用 **7.27c 自身的 compiler DLL、依赖和配置**。EXE 只导入 `KERNEL32.dll`，两版 DLL 均提供 `CreateInterface` / `VApplication001`；此静态依据之后又经过原创 JS 和三类真实面板资源的编译验证。不能据此认定任意不同版本的工具可混用。

| 工具                 | SHA-256                                                            |
| -------------------- | ------------------------------------------------------------------ |
| 7.22 通用 EXE 加载器 | `b8ab1d1a410b70845d69ef5776913d5016248359fbf80a3bb23b92989dbafbdd` |
| 7.27c compiler DLL   | `81139d9a49dae0b36c33087aa9c19879bdfecceb1fc6f2f6ce0d1249c977cbd1` |

编译脚本核对两侧构建与上述指纹，复制工具到客户端所在盘的私有 `.chronicle-build/skill-editor-7.27c`，再以相对只读搜索路径挂载本机 `dota`、`core`。隔离目录还需本版 `game/bin/sdkassettypes.txt` 等配置。直接在其他盘使用绝对挂载路径的首次探针未正确挂载；缺少编译配置的探针也明确失败，均未产生可用产物或改动真实客户端。

```powershell
node scripts/build-labyrinth-skill-editor.cjs "$Client727" "$Client722"
```

脚本只编译 [独立作者源](../tools/legacy-ability/7.27c/)，输出 `resources/skill-editor/7.27c` 的四份原创文件和清单。清单为 `schema: 1`、`clientBuild: 4397`、`profile: "727c-aghanim-v1"`，逐项记录固定目标及 SHA-256。工具、Valve 配置、客户端资源和临时编译目录均不包含在发行负载中。运行时名称索引由本机原包生成，为独立的第五份租约文件。

### 原生源码入口

本机冷启动先等待主菜单稳定，再进入精确的 `aghanim/main`。守护等待玩家锁定冥界亚龙后才请求面板，取得由引擎认证的本机 GUI 请求和 `UI_READY`。面板展示中文名称，目录读回 695 项默认技能、2,243 项全部定义，临时名称索引包含 1,717 项名称。ASCII GUI 搜索 `lina` 返回 4 项。

真实面板点击添加 `lina_dragon_slave` 等级 1，点击「+」升至等级 2，再点击删除，服务端均确认成功。删除后固定读回检查的 15 个原始技能槽、实例、名称及等级与基线相同。私有固定验证模块还调用新增技能执行实际施放，观测如下；魔法净减少和冷却读回包含短暂的采样延迟，不作为技能静态数值定义。

| 技能等级 | 魔法净减少 | 冷却读回 | 目标生命减少 |
| -------: | ---------: | -------: | -----------: |
|        1 |         99 |   7.5 秒 |           85 |
|        2 |        114 |   7.4 秒 |          160 |

另观察到用户通过面板添加等级 1 的 `abyssal_underlord_pit_of_malice`；这仅补充该次添加结果，不代表用户完成全部动作或该技能效果已系统验收。固定文件加载在不加 `-dev` 的启动中通过；该客户端没有识别行内 `script` 命令入口。

结束后五份工具租约文件和一份私有验证文件已恢复或清除。13 个原文件（含迷宫入口及 KV）、两条 Steam 路由、临时 CFG、绑定和媒体配置均与基线一致，游戏和守护退出。私有测试脚本、客户端名称索引和原生日志不进入发行包。
