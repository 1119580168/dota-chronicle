# 本地房间与旧版入队

## 普通房间

在“本地房间”选择同版本客户端、普通比赛、游戏 UDP 端口和房间密码，再点击“一键本地开服”。房主客户端必须保持开启。

0.3.2 为 6.77c、6.78b、6.80c、6.81、6.83、6.85b、6.88c 补齐房主初始化。守护进程等待原生地图加载、本地真人连接和选人阶段，再发送 `cmd jointeam good`，使房主进入天辉的原生选人界面。它不会选择英雄或填充 Bot。

旧入口移除了单人 Bot 练习流程以保留真人席位，却没有补充房主分队步骤。只在启动参数的 `map` 后追加入队命令仍可能早于玩家初始化；固定帧数的延迟也不能作为就绪判断。

其他玩家先连接，**等待地图加载完成后**再在游戏控制台选择队伍：

```text
jointeam good
```

上面是天辉；夜魇使用 `jointeam bad`。不要把选队命令和 `connect` 同时粘贴执行。然后使用该客户端的原生选人界面选择、锁定英雄。

7.32 / build 5397 普通比赛沿用专服入口。房主点击“房主加入”，载图后用 `jointeam 2` 或 `jointeam 3` 入队，真人就位后再补 Bot。官方活动、游廊、加入房间、单人比赛和原型版不会执行普通房主自动分队。

## WikiBox 历史沙盒快照

0.3.4 新增 WikiBox 2022 固定原包，目录共 16 个唯一地图入口：9 个官方活动、7 个游廊入口。WikiBox 是沙盒工具地图；作者仍维护当前版本，本次历史快照不是停更 RPG。同一张卡片提供 7.27c、7.30e、7.32、7.37e 四个客户端选项，默认 7.32，不为每个选项重复建立地图卡片。

在地图详情选择客户端后，启动、语言和本地房间跟随该选择；进入房间页时保留 WikiBox，语言使用该客户端单独保存的设置。房间页切换客户端时，如果目标客户端仍包含 WikiBox，就保留地图；不包含时回到普通比赛并提示。未绑定或已确认不兼容的组合不能启动、开服或加入，验证说明只属于所选客户端，不套用其他版本的成功记录。

房主和来客必须使用**相同实际客户端构建与相同固定原包**。四个选项用于分别测试兼容性，不代表不同版本之间可以互联。加入流程挂载核验后的固定包，再连接房主；不会通过工坊 ID 自动替换为当前最新版，也不会另开本地比赛。

WikiBox 原包会自动请求作者的 **FiveCloud** 服务，包括初始化、携带 Steam 身份与昵称的登录、成绩、排行榜、反馈和错误日志相关接口。启动器完全离线，与地图自身的外网行为分别说明。**基础工具验证、严格断网验证和跨机多人验证是独立项目**：载图、移动或技能测试通过，不代表外部接口不存在、断网完整流程可用或多人已验收。本轮各客户端状态、原包指纹与网络调用范围见 [WikiBox 兼容性记录](wikibox-compatibility.md)。

## 初始化与恢复

旧版房主的内部控制使用原客户端支持的 netcon，选择临时端口，每次生成 256 位随机口令；早期 Source 2 另需要 `-vconsole`。守护进程只从回环地址连接，核对游戏 PID、路径、创建时间及端口所属进程后才发送口令和命令。口令不写入绑定配置、会话状态或界面；Source 2 原生日志中的启动口令会在初始化完成和退出时脱敏。这个端口不是玩家连接地址，不应转发或分享。

就绪判断要求完整 `status`、`dota` 地图、活跃的本地回环玩家、至少一名真人、零 Bot 和 `HERO_SELECTION`。超时、已错过选人、身份变化、认证失败或停止请求不会被报告为成功。初始化只记录命令已发送，不能据此宣称实际阵营、整场比赛或跨机多人已验收。

停止仍通过本程序记录的进程身份执行；退出后恢复 Steam 路由、清理原字节匹配的会话 CFG。初始化失败会结束本次游戏并执行同样的恢复；窗口关闭不会提前释放游戏仍在使用的租约。

## 连接范围

玩家使用相同实际构建、自己的 Steam 账户和相同活动原包。只分享游戏 UDP 地址和房间密码。局域网使用房主 IPv4；异地连接需要可互访的虚拟网络地址或可入站的公网 UDP 转发。`sv_lan 0` 不会生成公网 IP。

程序不修改防火墙、路由器或系统安全设置。游戏触发 Windows 防火墙弹窗时须由用户处理。本次修复不代表两台电脑、两个账户和中途加入已经通过验证。

实机与回归范围见 [验证记录](validation.md)。
