## 收费静态审计

审计逐项覆盖原包 Lua、物品/KV、本地化文本，以及全部解码后的 Panorama JavaScript、XML、CSS。检查支付、VIP、票证、捐赠与奖励字段，并沿实际调用核对权限、奖励来源和外部请求。本次静态审计没有执行地图代码，也没有访问作者后台。

**这个固定原包中未发现实际收费功能、付费身份或捐赠奖励链。** 关键误报已复核：

- `Premium`、票证相关接口位于内嵌 API 参考或全游戏语言文本，不构成地图实际收费调用。
- 购买事件、`DOTA_UNIT_ORDER_PURCHASE_ITEM` 等属于局内金币购物。
- 全部 27 个编译 UI 解码后没有发现支付、VIP 或捐赠奖励入口；宽泛 `vip` 搜索命中的是 Viper 英雄样式。
- FiveCloud 的真实请求用于初始化、登录、成绩、排行榜、反馈和错误日志，未发现支付回调或按现实货币授予游戏奖励的路径。

作者公开页面没有提供明确的永久免费承诺。结论仅覆盖本表指纹的包，不推断其他历史包、最新版或外部后台从未收费；免费订阅也不能单独作为收费检查依据。

## 外网请求与离线边界

原包配置的 FiveCloud 基础地址是 `https://api.holemystery.com/fivecloud`。这些调用存在于实际初始化和事件流程，不只是 SDK 示例：

| 触发点              | 原包调用                                                                                     | 作用                            |
| ------------------- | -------------------------------------------------------------------------------------------- | ------------------------------- |
| 设置队伍阶段        | `GameStateCustomGameSetup → FiveCloudSDK:keyInit`，请求 `/app/setKey` 或 `/app/getKeyStatus` | 初始化服务状态                  |
| HUD 初始化          | `FiveCloudInit → FiveCloudSDK:Login → /dota2/user/login`                                     | 自动登录，携带 Steam 身份与昵称 |
| 娱乐斧王模式        | `/dota2/happyAxe/start`、`/end`、`/list`                                                     | 开始记录、上传成绩与请求排行榜  |
| 玩家反馈 / 错误追踪 | `/dota2/feedback/edit`、`/dota2/log/edit`                                                    | 提交反馈与错误信息              |
| 连接、重连与离开    | 登录 / 退出请求                                                                              | 更新在线状态                    |

请求设置 3 秒绝对超时；状态码为 0 时最多重试 3 次，成功响应才进入回调。服务成功后设置 `SERVERMODE`；该变量还区分本地主机与服务器的部分操作方式，没有发现收费权限判断。

静态代码没有显示基础沙盒操作必须等待服务成功；排行榜、上传和反馈依赖外部服务。不过，**地图原包存在自动外网请求**，不能把它描述为无网络调用或已完成严格离线验证。启动器本身完全离线，与第三方地图代码的网络行为分别说明。断网后的完整流程仍待测试，不因基础操作通过而省略该项。

## 兼容性依据与实测结果

旧包 `scripts/vscripts/five_system/init/game_config.lua` 在初始化时无保护调用 `GameMode:SetFreeCourierModeEnabled(true)`。本机 7.22、7.23e 的 `server.dll` 未发现该名称，存在初始化接口风险；7.27c、7.30e、7.32、7.37e 中能找到该名称。娱乐模式另有 Marci、Primal Beast 技能引用，基础 UI 正常不代表该模式兼容。
